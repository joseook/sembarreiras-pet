Privacidade no protótipo

Este é um projeto acadêmico demonstrativo. Estas informações descrevem o funcionamento atual do site.

Dados nos formulários

Login, cadastro, contato e agendamento são demonstrações. Os campos são validados no navegador; os dados digitados não são enviados nem salvos pelo projeto. Não existe uma conta real ou um banco de dados conectado ao site publicado.

Use dados fictícios para experimentar os formulários.

Hospedagem e serviços externos

O site é publicado no GitHub Pages. O serviço de hospedagem pode processar informações técnicas de acesso conforme suas próprias condições.

Se uma chave do Google Maps estiver configurada, a página Como funciona carrega o mapa do Google. Nesse caso, o navegador se conecta a esse serviço externo.

Antes do cadastro real

Uma política de privacidade completa deverá ser publicada antes da implementação de contas e do envio de dados reais, explicando o tratamento de dados, os responsáveis e os canais de atendimento.
